PC BOOSTER 0.2.0 — WINDOWS 10/11 x64

КОМПАКТНАЯ СБОРКА
Все функции приложения сохранены. Для уменьшения размера установочные файлы .NET не включены в архив.

ОДНОРАЗОВОЕ ТРЕБОВАНИЕ
Нужен Microsoft .NET 10 Desktop Runtime (x64).
Официальная страница Microsoft:
https://dotnet.microsoft.com/en-us/download/dotnet/10.0
В разделе .NET Desktop Runtime выбери Windows x64 и установи его.
Это системная среда выполнения, а не дополнительная программа PC Booster.

ЗАПУСК
1. Распакуй ZIP в обычную папку.
2. Запусти PC Booster.exe.
3. Интернет нужен только для AI-помощника. Диагностика и локальные настройки работают на компьютере.

ВАЖНО
Твики изменяют только перечисленные параметры текущего пользователя Windows.
Исходные значения сохраняются для отмены.
Не применяй настройки, смысл которых тебе непонятен.
